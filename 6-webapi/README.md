# Подключение сервисов через Web API (групповое)

Работа выполняется группами по 2 человека.

Реализуйте обмен данными через API веб-сервиса на выбор (VK, мессенджер, облачные хранилища и т.д.)

_Пример:_

Используйте [Javascript API Dropbox](https://www.dropbox.com/developers/documentation/javascript#overview) для

- получения списка файлов пользователя
- создания нового файла в Dropbox пользователя

[Регистрация приложения в Dropbox](https://e.sfu-kras.ru/Регистрация%20приложения%20в%20Twitter)
