    Как пользоваться

    Нажмите миниатюру, чтобы открыть её крупно. В окне просмотра доступны кнопки перехода к предыдущему и следующему кадру.

    Категории

    Вкладки позволяют быстро отфильтровать изображения по категориям.

    Технологии

    Описание галереи загружается из JSON через $.ajax; интерфейс построен на jQuery UI.
